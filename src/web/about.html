InstaViewer

À propos

Instaviewer n'est ni promu par, ni affilié à Instagram.

Instaviewer est un simple interpreteur des données ; il n'interagit à aucun moment avec Instagram : aucune API n'est utilisée. Le script lit uniquement l'archive de données que vous avez téléchargée depuis les serveurs d'Instagram.

Vos données sont uniquement traitées par ce script en local, sur votre ordinateur. Lors de l'utilisation de ce script, aucune donnée n'est envoyée sur Internet, ni stockée par Instaviewer.

Les données visibles ici correspondent à l'état de votre compte au moment de l'exportation de l'archive depuis les serveurs d'Instagram ; aucune donnée n'est actualisée en direct.
